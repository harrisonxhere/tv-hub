## Install / 安装

```bash
adb install -r openapk-tv-1.0.4.apk
```

Android 9+ · arm64-v8a / armeabi-v7a / x86 · overwrite-installable from v1.0.2
Android 9 以上 · 三种 ABI 都支持 · 可从 v1.0.2 覆盖安装

Coming from v1.0.1 or earlier, uninstall the old version first: those builds used a different signing key.
从 v1.0.1 及更早版本升级的，请先卸载旧版：签名不同，系统会拒绝覆盖安装。
